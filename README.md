# 🤖 Local AI — локальный чат с ИИ и генерация картинок

Мой проект: **локальный чат** с нейросетями (**Qwen**, **DeepSeek**) + **генерация картинок** через **Z-Image Turbo**.

Всё работает **локально** — **без интернета**, **без подписок**, **без Google**.
Только твой компьютер и нейросети.

---

## 📋 Что это умеет

- 💬 **Чат с нейросетями** через Ollama (**Qwen**, **DeepSeek**)
- 🎨 **Генерация картинок** через Z-Image Turbo
- 📁 **История чатов** (сохраняется в JSON)
- 🏪 **Магазин моделей** (скачивание в 1 клик)
- 🌓 **Тёмная/светлая тема**
- ⚙️ **Настройки** (температура, контекст, top-k, top-p)
- 📊 **Счётчик токенов**
- 🧠 **Режим «Мышление»** (для DeepSeek-R1)

## 📥 Что установить

### 1. Ollama (для чата)

1. Скачай: **https://ollama.com/download**
2. Нажми **«Download for Windows»**
3. Установи (двойной клик → Install)
4. Дождись иконки Ollama в трее (рядом с часами)

### 2. Z-Image Turbo (для картинок)

1. Скачай: **https://github.com/airesearch-official/Z-Image-Turbo-Windows/releases**
2. Скачай **`Z-Image-Turbo-Windows-x64.exe`**
3. Установи в папку **БЕЗ русских букв** (например, `D:\Z-Image-Turbo`)
4. Запусти ярлык **«Z-Image Studio»**
5. Дождись автозагрузки моделей (~8-10 ГБ, 10-30 минут)
6. Когда увидишь `Ready. Open this link: http://127.0.0.1:9000` — всё готово
